# Canoe Hotkeys

A RuneLite plugin that adds customizable hotkeys to the canoe shaping dialog. When the "What sort of canoe would you like to make?" interface is open, pressing the configured key for each canoe type triggers that option without needing to click.

Defaults:

- Log canoe — `1`
- Dugout canoe — `2`
- Stable dugout canoe — `3`
- Waka canoe — `4`

Each hotkey can be reassigned in the plugin's config panel.

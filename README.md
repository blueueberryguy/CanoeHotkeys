# Canoe Hotkeys

Configurable hotkeys for choosing your canoe type at any canoe station - no more clicking between canoe types.

![Hotkey overlay on the canoe selection screen](https://github.com/user-attachments/assets/3d68d867-8ba7-40fb-aa91-6a0570194dfb)

## How it works

When the canoe shaping dialog opens ("What sort of canoe would you like to make?"), the plugin draws a small label over each canoe option showing its bound hotkey. Pressing that key fires the same action as clicking the option. The hotkeys are only consumed while the dialog is open — `1`-`4` still type normally in the chatbox, work in NPC dialog options, the bank, etc.

## Config

![Config panel](https://github.com/user-attachments/assets/aa3a705e-1e77-4a6d-9b54-eb87786eb3ec)

Each canoe type has its own keybind in the plugin's config panel. Defaults:

- Log canoe — `1`
- Dugout canoe — `2`
- Stable dugout canoe — `3`
- Waka canoe — `4`
